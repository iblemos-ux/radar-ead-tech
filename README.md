# Radar EaD Tech

Monitor de editais **gratuitos**, na modalidade **EaD**, em tecnologia (IA, Ciência de Dados, ADS, Programação e áreas afins), ofertados por instituições públicas brasileiras e triados para quem estuda a partir de **Pernambuco**.

## Como funciona

| Arquivo | Função |
|---|---|
| `index.html` | Estrutura da página |
| `style.css` | Visual (cores, fontes, layout, tema claro e escuro) |
| `app.js` | Lógica: filtros, prioridade, prazos, ficha do edital e acompanhamento |
| `dados.json` | Oportunidades e histórico de verificações, atualizados todo dia pela varredura automatizada |

O acompanhamento pessoal (interesse, inscrição, anotações) fica salvo apenas no navegador de quem usa a página.

## Classificação de viabilidade

- **A** — gratuito, elegibilidade confirmada e participação remota compatível a partir de PE
- **B** — participação permitida, com deslocamentos ou exigências a considerar
- **C** — informações insuficientes no edital
- **D** — restrição oficial impede a participação

As informações vêm de editais e páginas oficiais. Confira sempre o edital antes de se inscrever.
